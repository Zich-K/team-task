앱 열기
바로가기 아이콘 만들기
1
크롬 또는 엣지에서 위의 이 기기에 앱으로 설치를 누르세요 (버튼이 안 보이면 2번부터)
2
앱 열기 후 주소창 오른쪽 끝의 설치 아이콘(⊕ 또는 모니터 모양) 클릭
3
아이콘이 없으면 크롬 ⋮ → 전송, 저장, 공유 → 페이지를 앱으로 설치, 엣지 … → 앱 → 이 사이트를 앱으로 설치
4
설치를 누르면 바탕화면·시작 메뉴에 회사 로고 아이콘이 생기고, 별도 창으로 열립니다. 작업 표시줄에 고정해 두면 편합니다
1
크롬에서 앱 열기를 눌러 로그인
2
오른쪽 위 ⋮ 버튼
3
홈 화면에 추가 (또는 앱 설치) 선택
4
추가를 누르면 홈 화면에 회사 로고 아이콘이 생깁니다
1
사파리에서 앱 열기를 눌러 로그인
2
아래쪽 공유 버튼 (□↑)
3
홈 화면에 추가 선택
4
오른쪽 위 추가를 누르면 완료
